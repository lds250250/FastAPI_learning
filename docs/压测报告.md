## 六、已知风险和没做的事

| 风险 / 没做的事 | 说明 |
| --- | --- |
| **Redis 挂了会同时降级缓存和限流** | 缓存走数据库（变慢）**加上**限流全放行（不设防）—— **这是最危险的组合** |
| **压测机和被测机是同一台电脑** | 数字可能被本机 CPU / 网络压低，不是 NAS 的真实上限 |
| **没测 WebSocket** | locust 只压了 HTTP 接口 |
| **没测长时间运行** | 30 秒看不出内存泄漏、连接泄漏 |
| **数据库在 Docker 网络里** | 每次查询多一层转发，和"数据库在另一台机器"不完全一样 |
